# Acceptance Criteria

## 1. 正式驗收環境

正式驗收僅採用：

- Kubuntu 24.04。
- KDE Plasma。
- X11 工作階段。
- 實體電腦人工測試。

Wayland 不列入第一版功能驗收；只驗證程式能偵測並拒絕執行。

本專案最終驗收方式依使用者決策採實機人工測試，不要求 GitHub Actions 自動測試作為正式驗收條件。

## 2. 第一階段：安全可行性閘門

這是最高優先級。未通過不得進入完整 Capture Backend 開發。

- [ ] 在 Kubuntu 24.04 KDE X11 確認工作階段類型。
- [ ] 確認可取得目標視窗識別資訊。
- [ ] 證明隔離式虛擬顯示可建立。
- [ ] 證明建立過程不改變主要螢幕解析度。
- [ ] 證明建立過程不改變主要桌面排列。
- [ ] 證明建立過程不造成桌面跳動。
- [ ] 證明不改變其他視窗的位置與尺寸。
- [ ] 證明可在隔離環境中操作本次目標視窗。
- [ ] 證明移除隔離資源後主要桌面維持原狀。
- [ ] 證明失敗時也能清理已建立資源。

**Gate：** 任一安全條件無法證明，即判定此方案未通過。停止後續截圖流程，不得改用會改變主要桌面配置的方式繼續。

## 3. 啟動與環境檢查

- [ ] AppImage 可啟動。
- [ ] 啟動時正確偵測 X11。
- [ ] 偵測到 Wayland 時顯示尚未支援並禁止截圖。
- [ ] 缺少必要系統工具時顯示具體依賴名稱。
- [ ] 虛擬顯示能力檢查失敗時禁止截圖。
- [ ] 單一實例限制正常。
- [ ] 設定可在重新啟動後載入。
- [ ] 不會自行加入 KDE 登入自動啟動。

## 4. 小型操作視窗

- [ ] 啟動只顯示小型快速操作視窗。
- [ ] 不顯示 CAPTURE PROFILE 標籤。
- [ ] Profile 選單直接顯示名稱與解析度。
- [ ] 不重複顯示 Profile 尺寸詳細卡片。
- [ ] 不顯示 Settings → Open full settings window 提示文字。
- [ ] 有明確的 Capture Window 按鈕。
- [ ] 顯示目前快捷鍵。
- [ ] 只顯示最近一次截圖資訊。
- [ ] 不顯示圖片預覽。
- [ ] 齒輪只負責開啟完整 Settings。
- [ ] Minimize 一般最小化至工作列。
- [ ] Close 會結束程式。

## 5. Settings 與 Profile

- [ ] Settings 使用獨立大型視窗。
- [ ] 左側垂直分類，右側設定內容。
- [ ] 分類包含 Profiles、Shortcut、Output、Application、System。
- [ ] Profiles 頁面可選擇 Profile。
- [ ] 選擇後可直接在同一頁編輯名稱。
- [ ] 選擇後可直接在同一頁編輯寬度。
- [ ] 選擇後可直接在同一頁編輯高度。
- [ ] 可新增 Profile。
- [ ] 可刪除 Profile。
- [ ] 可設定預設 Profile。
- [ ] 不出現 Profile 管理齒輪。
- [ ] 不出現 Manage Profiles 文字按鈕。
- [ ] 不開啟獨立 Profile 管理 Dialog。
- [ ] Profile 切換不會意外丟失尚未 Apply 的修改。
- [ ] Apply 保存設定。
- [ ] Cancel 捨棄尚未保存的修改。
- [ ] 無效尺寸與空白名稱不能套用。

## 6. Shortcut

- [ ] 預設 Shift + Print Screen。
- [ ] Record Shortcut 可錄製組合鍵。
- [ ] 可修改快捷鍵。
- [ ] 能偵測或提示快捷鍵衝突。
- [ ] 不覆寫其他應用程式的快捷鍵設定。
- [ ] 快捷鍵直接截取滑鼠所在視窗，不需點擊。
- [ ] 快捷鍵使用目前預設 Profile。
- [ ] 快捷鍵截圖不主動開啟 GUI。

## 7. Window Picker

- [ ] GUI Capture 按鈕會隱藏小型 GUI。
- [ ] 滑鼠移入可選視窗時顯示高亮邊框。
- [ ] 點擊後正確鎖定目標 Window ID。
- [ ] 不會選取程式自己的 GUI 或進度視窗。
- [ ] Esc 立即取消。
- [ ] Esc 不修改視窗或桌面。
- [ ] 取消後恢復小型 GUI。

## 8. Window State Snapshot and Restore

- [ ] 保存目標 Window ID。
- [ ] 保存原始位置與尺寸。
- [ ] 保存最大化狀態。
- [ ] 保存全螢幕狀態。
- [ ] 保存虛擬桌面。
- [ ] 保存螢幕指派。
- [ ] 保存原始顯示配置資訊。
- [ ] 一般視窗成功後恢復。
- [ ] 最大化視窗成功後恢復。
- [ ] 全螢幕視窗成功後恢復。
- [ ] 不同虛擬桌面視窗成功後恢復。
- [ ] 不同螢幕視窗成功後恢復。
- [ ] 截圖失敗後仍執行恢復。
- [ ] 恢復完成後清除暫時顯示資源。

## 9. Exact Screenshot

- [ ] 最終 PNG 寬度精確符合 Profile。
- [ ] 最終 PNG 高度精確符合 Profile。
- [ ] PNG 只包含應用程式 Client Area。
- [ ] PNG 不包含 KDE 標題列、視窗邊框或陰影。
- [ ] 擷取範圍不裁掉 Client Area 的有效內容。
- [ ] 不因 XWD 轉換或擷取範圍錯誤引入非預期黑邊。
- [ ] 不以事後縮放補救錯誤尺寸。
- [ ] 不支援調整尺寸的視窗會中止。
- [ ] 截圖失敗會顯示原因。
- [ ] 不會以原始視窗尺寸偷偷替代。

## 10. Output

- [ ] PNG 儲存可獨立啟用。
- [ ] 剪貼簿可獨立啟用。
- [ ] 至少一種輸出方式必須啟用。
- [ ] PNG 儲存到設定目錄。
- [ ] 預設目錄為 ~/Pictures/Screenshots。
- [ ] Browse 開啟 KDE 原生資料夾選擇器。
- [ ] 檔名包含視窗名稱與日期時間。
- [ ] 同名檔案自動附加流水號。
- [ ] 絕不覆蓋既有圖片。
- [ ] 剪貼簿包含 PNG 影像資料。

## 11. Progress and Notification

- [ ] GUI 截圖顯示獨立小型進度視窗。
- [ ] 進度視窗顯示目前階段。
- [ ] 完成後返回小型主畫面。
- [ ] 快捷鍵截圖使用非干擾式 KDE 通知。
- [ ] 成功通知只在復原確認成功後顯示。
- [ ] 失敗通知說明原因。
- [ ] 復原失敗通知提供修復指引。

## 12. System Tray

- [ ] 左鍵開啟小型 GUI。
- [ ] 右鍵顯示功能選單。
- [ ] 選單包含 Capture。
- [ ] 選單包含 Select Profile 子選單。
- [ ] 選單包含 Open GUI。
- [ ] 選單包含 Quit。
- [ ] 系統匣 Capture 使用目前選定 Profile。

## 13. Recovery and Diagnostics

- [ ] 復原失敗會觸發自動復原程序。
- [ ] 保留狀態快照。
- [ ] 提供人工修復指引。
- [ ] 可複製診斷報告。
- [ ] 保留最近五次執行的技術紀錄。
- [ ] 不保存截圖內容。
- [ ] 日誌不包含影像像素或剪貼簿內容。

## 14. AppImage

- [ ] Python runtime 已打包。
- [ ] PySide6 已打包。
- [ ] 應用程式資源已打包。
- [ ] 主機端 X11/KDE 依賴有啟動檢查。
- [ ] 缺少依賴時顯示清楚訊息。
- [ ] AppImage 可在目標 Kubuntu 環境執行。
- [ ] GitHub Releases 可下載版本。
- [ ] 不提供程式內更新功能。

## 15. 最終判定

只有在隔離顯示安全閘門通過，且上述必要項目在 Kubuntu 24.04 KDE X11 實機人工測試通過後，才能宣告第一版可用。

若隔離顯示安全閘門未通過，專案狀態應明確標記為技術可行性未通過，不得宣稱完成指定尺寸截圖功能。
